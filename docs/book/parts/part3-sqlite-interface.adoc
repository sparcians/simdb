= Part III: The SQLite Interface

SimDB's SQLite layer is useful on its own, with no pipelines involved. This part
is a complete tour of the data layer: schema, inserts, queries, transactions,
blobs, and inspection.

== Defining a Schema

Describe your tables in C++.

*Objectives*

* Build a `Schema` with tables, typed columns, and constraints.
* Use defaults, indexes, and uniqueness where appropriate.

*Key topics*

* `SqlDataType` (int/uint widths, `string_t`, `blob_t`, ...).
* `addTable` / `addColumn`; `setColumnDefaultValue`.
* Indexes (`createIndexOn`), `ensureUnique`, primary-key control
  (`unsetPrimaryKey`).
* Appending schema incrementally over the run.

*Sources & reusable snippets*

* `include/simdb/schema/SchemaDef.hpp`, `include/simdb/schema/Blob.hpp`.
* `README.md` -- "Database Creation".
* `include/simdb/apps/argos/ArgosCollector.hpp` -- rich real-world
  `defineSchema` example.

== Inserting Data

Two ways to write rows, and when to use each.

*Objectives*

* Insert with the one-shot `INSERT` API.
* Prepare and reuse statements for high-volume inserts.

*Key topics*

* `SQL_TABLE` / `SQL_COLUMNS` / `SQL_VALUES` macros.
* `prepareINSERT`, `setColumnValue`, `createRecord`.
* Why prepared statements matter for throughput.

*Sources & reusable snippets*

* `include/simdb/sqlite/PreparedINSERT.hpp`.
* `README.md` -- "Record INSERT".

*Sources & reusable snippets*

* `include/simdb/sqlite/Transaction.hpp`.

== Blobs, Compression & Serialization

*Key topics*

* `Blob` and `ValueContainer` handling.

* Serialization patterns for vectors/structs.

*Sources & reusable snippets*
